# Simulación y análisis de señales con la Transformada de Fourier

Proyecto de la materia de Lenguaje Ensamblador. Autor: Marco Antonio Contreras.

## Descripción
Este código genera señales elementales (senoidal, pulso rectangular y escalón),
calcula su Transformada de Fourier con np.fft.fft() y grafica su magnitud y fase.
También verifica tres propiedades: linealidad, desplazamiento en el tiempo y escalamiento.

## Requisitos
Python 3.12 o superior, con NumPy, SciPy y Matplotlib (pip install numpy scipy matplotlib).

## Cómo ejecutarlo
python senales.py
